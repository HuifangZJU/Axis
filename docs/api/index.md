# API reference

AXIS follows the [scanpy](https://scanpy.readthedocs.io) layout:

| Module | Purpose |
|---|---|
| [`axis.pp`](pp.md) | canvases and molecular pseudo-images |
| [`axis.tl`](tl.md) | transition fields, generation, matching, integration |
| [`axis.pl`](pl.md) | plotting |
| [`axis.metrics`](metrics.md) | evaluation metrics |
| [`axis.registration`](registration.md) | networks, losses, training, warping |
| [`axis.generation`](generation.md) | evidence planes, weights, generator |
| [`axis.matching`](matching.md) | reference reconstruction, contrasts, population integration, cross-modality |
| [`axis.settings`, `axis.config`, `axis.io`](settings.md) | data locations, dataset configs, file layout |
